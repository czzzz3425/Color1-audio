# 小跟班：连续作业

跟班亲自到场完成动作，玩家可以提前安排下一步，不必等待它每次返回。

- 点击目标立即显示铅笔标记。深色表示当前任务，浅色表示下一步。
- 飞行按距离取 0.3–0.6 秒，用平缓弧线；上色轻触 0.16 秒，吸收收拢 0.22 秒。完成动作才改变目标。
- 最多预存一个下一步指令。再点其他目标会替换下一步，当前动作不被打断。同目标同种操作重复点击不叠加。
- 完成上色、吸收或宝箱交互后，直接飞往下一目标，不绕回玩家。没有下一步时停留 `Return Delay`（默认 0.6 秒），然后返回；停留或返回中都能接新指令。
- 吸收完成动作就入库，可以立刻用于附近目标，不必等跟班带回。复合元素由目标内部返还，不重复入库。
- 上色接单时预留种子。替换待办、目标消失、超出玩家工作圈、上色失败、切关或死亡取消指令时，未用出的种子退回。
- 飞行中存档将尚未使用的预留种子计入存档库存；读档不恢复半途任务，也不会丢种。
- 保持跟随时的角色尺寸与贴图纵横比例，呼吸、起落只轻微变形。超时提醒仍默认关闭。

实现：`scripts/companion.gd`、`scripts/companion_order_marker.gd`。测试：`tests/test_companion_orders.gd`（独立 APPDATA 目录，不使用实际存档）。
