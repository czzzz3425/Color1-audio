# 红心、蓝心宝箱

将 `prefabs/items/interaction/chest_red_heart.tscn` 或 `chest_blue_heart.tscn` 拖入关卡即可。仍由玩家点击宝箱、跟班飞去开箱；玩家走近掉落的心即可拾取。

红心和蓝心都使最大生命增加 1，并恢复新增的 1 点生命；本次游戏跨关卡、死亡保留，重新运行后重置。世界道具使用各自彩色图片，生命栏统一使用黑白心。

也可以选中现有宝箱，将 Drop Scene 拖入 `red_heart.tscn` 或 `blue_heart.tscn`。Health Bonus 在心道具预制体中配置。Drop Id 默认留空，会按宝箱所在路径区分；如果手动填写，请为每件心使用唯一编号，重复编号只生效一次。

动画包括：开箱轻微挤压回弹、道具抛物线弹出、落地悬浮、拾取放大后飞向玩家并缩小淡出，以及生命栏新增心的回弹。受伤时对应的心轻轻挤压，空心降低亮度，小数血量用亮度体现。

心的世界贴图缩放为 1.35，生命栏图标为 56 像素。红心、蓝心带有与钥匙同款的放射光芒，分别使用暖红和冰蓝色；光芒随掉落回弹展开，拾取时随道具一起缩小淡出。
