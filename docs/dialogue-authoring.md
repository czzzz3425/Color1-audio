# 剧情文案策划操作指南

按顺序完成：**写文案 → 放触发器 → 配置 → 运行检查**。不需要打开或修改任何 `.gd` 文件。

## 1. 编写剧情文案

在 Godot 左下角“文件系统”中找到 `dialogue/dia/`。

- 修改现有剧情：双击 `companion.dialogue`，进入 **Dialogue** 编辑页。
- 新写剧情：复制 `story_template.dialogue`，改名为 `level1_story.dialogue` 等名称，保留 `.dialogue` 后缀，然后双击打开。

照下面的格式填写：

```text
~ river_meeting
予风: 前面好像过不去了。
小白: 试试把水冻住吧！
=> END
```

| 内容 | 怎么填写 |
| --- | --- |
| `~ river_meeting` | 这段剧情的名字，建议用英文和下划线；同一文件内不能重名。不会显示给玩家。 |
| `予风: 台词` | 角色名、英文冒号、台词。每句写一行。 |
| `=> END` | 这段剧情的结束标记，保留即可。 |

一个文件可以放多段剧情，每段使用不同的名字。只修改台词时，不要改段落名。角色名要与立绘配置一致，目前已配置“予风”和“小白”。

需要选项时，照模板填写：

```text
~ river_choice
小白: 要一起过去吗？
- 一起走吧。
	小白: 好，出发！
- 我再看看。
	小白: 那我等你。
=> END
```

`-` 后是玩家选项，选项下面的回复需要缩进：在行首按一次 **Tab**。写完按 **Ctrl+S** 保存。

## 2. 将触发器拖入关卡

1. 在文件系统双击目标关卡，例如 `scenes/level_1.tscn`，打开 **2D** 编辑页。
2. 找到 `prefabs/rooms/dialogue_trigger.tscn`，将它拖到关卡画面中。
3. 在左侧场景树选中新增的 **DialogueTrigger**，拖动到剧情发生的位置。
4. 蓝色圆圈就是触发范围。找不到位置时，在 2D 画面按 **F** 定位选中的触发器。

请使用 **dialogue_trigger.tscn**。名称相近的 `companion_hint.tscn` 是旧的跟班提醒点，必须招募跟班后才生效。

## 3. 在右侧 Inspector 配置

选中触发器后，在右侧 **Inspector（检查器）** 填写以下内容；找不到时向下滚动或展开“剧情触发”。

| 字段 | 用途与填写方法 |
| --- | --- |
| **Dialogue Resource** | 播放哪个文案文件。从文件系统将自己的 `.dialogue` 文件拖到此栏。 |
| **Cue** | 播放哪段剧情。从下拉框选择，如 `river_meeting`。 |
| **Trigger Mode** | “进入区域”：走进范围自动播放；“按键交互”：走进范围后按 **E** 才播放。 |
| **Area Shape** | 选择“圆形”或“矩形”。 |
| **Radius** | 圆形的半径。默认 256，约一格；数值越大范围越大。 |
| **Area Size** | 矩形的大小：X 是宽，Y 是高。只在矩形模式使用。 |
| **Repeat Mode** | 设置播放次数，见下表。 |
| **Story Id** | 选择“整局一次”时必填，如 `level1_river_meeting`。不同剧情用不同名字。 |
| **Interaction Text** | 按键交互时显示的提示，可改成“按 E 查看”等文字。 |
| **Show Range In Game** | 勾选后，运行游戏也能看到范围，方便检查；检查完关闭。 |

播放次数如何选择：

| 选项 | 适合什么情况 |
| --- | --- |
| **整局一次** | 重要剧情。切关后返回也不会重播；重新运行游戏后可以再次播放。必须填 Story Id。 |
| **每次进入关卡一次** | 地点介绍。本次进入只播一次，离开并重新加载关卡后可再播。 |
| **每次进入区域** | 可重复提示。自动模式需要离开再进入；按键模式可再次按 E。 |

**例子：走到河边自动播放一次剧情**

选择自己的文案文件 → Cue 选 `river_meeting` → Trigger Mode 选“进入区域” → Repeat Mode 选“整局一次” → Story Id 填 `level1_river_meeting` → 把蓝色范围放在河边入口。

需要多个触发点时，重复拖入预制体，分别配置。若复制已有触发器用于另一段剧情，记得修改 **Cue** 和 **Story Id**。

## 4. 保存并运行检查

1. 按 **Ctrl+S** 保存文案和关卡。
2. 按 **F5** 从游戏入口运行，走到触发位置；按键模式还需要按 **E**。
3. 检查播放的段落、触发位置、立绘及选项是否正确。
4. 测试“整局一次”时，停止游戏并重新运行，才能再次触发。

多个剧情同时触发会依次播放。已排队的剧情不会因走出范围而取消，切关会取消尚未播放的剧情。范围不检查墙壁遮挡，摆放时避免覆盖隔壁房间。

## 5. 常见问题

| 问题 | 检查哪里 |
| --- | --- |
| 没有触发 | 文案和关卡是否保存；Cue 是否已选；整局一次是否填 Story Id；是否已播放过；按键模式是否按了 E。 |
| 下拉框没有新段落 | 先保存文案，等待文件导入，再选触发器。改了段落名后，需要重新选择 Cue。 |
| 看不到范围 | 在编辑器 **2D** 页选中触发器并按 F；游戏运行画面中需勾选 Show Range In Game。 |
| 节点出现黄色警告 | 点击警告查看说明，通常是文案、段落或 Story Id 没填。 |
| 文案有红色报错 | 检查英文冒号、段落名、结束标记和选项回复的缩进；不确定时重新复制模板。 |
| 角色没有立绘 | 台词里的角色名必须与立绘配置中的 Character Name 完全一致。 |

## 附：调整立绘

双击 `dialogue/portraits/player.tres`（予风）或 `companion.tres`（小白），在 Inspector 修改：

| 字段 | 作用 |
| --- | --- |
| **Portrait** | 拖入立绘图片，推荐透明背景 PNG。 |
| **Side** | 从左侧或右侧出场。 |
| **Size Multiplier** | 大小倍率，越大人物越大，可以直接输入超过 3 的值。 |
| **Position Offset** | X 正数向右、负数向左；Y 正数向下、负数向上。 |
| **Flip H** | 左右镜像图片。 |

保存后重新播放对话查看效果。新增角色：在文件系统新建 **CharacterPortrait** 资源，填角色名和图片；打开 `dialogue/balloon.tscn`，选根节点，在 **Character Portraits** 数组新增一项并拖入该资源。

目前支持地点触发和 E 键交互；拿到道具后触发、完成前一段剧情后解锁等条件，暂时需要找程序协助。
