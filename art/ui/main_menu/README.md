# 主菜单标题美术

1. 将完整标题图片（含「失色」「招领处」）放进本目录，推荐 `title.png`。
2. 打开 `scenes/game.tscn`，选中根节点 **Game**。
3. 在 Inspector 的 **主菜单美术** 分组，将图片拖入 **Menu Title Texture**。
4. 使用 **Menu Title Size** 调整显示区域，默认 280 × 160。图片始终等比缩放，不裁切、不拉伸。
5. 按 F5 预览。清空贴图即可恢复手写文字占位。

## 交付建议

- 透明背景 PNG；深石墨色铅笔线稿，适配暖灰纸面。
- 建议按显示区域的 3 倍绘制，例如 840 × 480；减少图片四周多余透明留白。
- 将完整标题绘制在一张图片中，自行安排主次、错位与复描。
- 图片保留美术原色，不附加文字占位的染色效果；菜单淡出仍正常生效。
- 不需要绘制按钮文字。开始游戏、设置等文字由菜单字体统一显示。

## 菜单字体

默认使用霞鹜文楷轻便版 Regular。字体来源：
https://github.com/lxgw/LxgwWenKai-Lite

字体文件与 SIL OFL 1.1 许可证保存在 `art/fonts/`。
可在 Game 根节点的 **Menu Font** 替换字体，无需修改脚本。
